# 검색 노출 운영 가이드

기술 세팅은 끝났습니다. 사이트맵, 구조화 데이터, canonical, 모바일 대응, 속도 — 이 부분은 이미
경쟁 로펌 사이트보다 유리한 상태입니다.

문제는 **그 다음이 8할**이라는 것입니다. 이 문서는 그 다음에 대한 것입니다.

---

## 1. 현실 인식부터

### 구글과 네이버는 다른 게임입니다

| | 구글 | 네이버 |
| --- | --- | --- |
| 무엇을 보나 | 콘텐츠 품질, 피인용, 체류시간 | 자사 서비스 우선, 최신성, 문서 형식 |
| 신규 사이트 | 3~6개월이면 롱테일부터 잡힘 | 홈페이지만으로는 한계가 큼 |
| 전략 | 이 사이트에 집중 | 블로그 병행 + 플레이스 등록 |

네이버는 검색 결과 상단을 자사 서비스(블로그, 지식iN, 카페, 플레이스, 인플루언서)로 채웁니다.
외부 홈페이지가 노출되는 자리는 그 아래 "웹사이트" 영역이고, 면적이 작습니다.

**그래서 네이버는 홈페이지 SEO만으로 이기려 하면 안 됩니다.**
네이버 블로그를 따로 운영하면서 홈페이지로 유입을 보내는 구조가 현실적입니다.

### "학교폭력 변호사"는 당장 노리는 키워드가 아닙니다

대표 키워드는 이미 대형 로펌과 광고비를 쓰는 곳들이 점유하고 있습니다. 신규 사이트가 6개월 안에
1페이지에 올라갈 가능성은 낮습니다.

대신 **실제 문의로 이어지는 것은 롱테일**입니다. 검색하는 사람의 상황이 구체적일수록 전환율이
높습니다. "학교폭력 변호사"를 검색하는 사람보다 "학폭위 서면진술서 쓰는 법"을 검색하는 사람이
훨씬 절박하고, 훨씬 빨리 전화합니다.

## 2. 키워드 지도

### 이미 페이지가 있는 것 (대표·중간 키워드)

| 페이지 | 노리는 키워드 |
| --- | --- |
| `/` | 학교폭력 변호사, 학폭 변호사 |
| `/school-violence/` | 학교폭력 절차, 학폭위 절차, 학교폭력 처리 과정 |
| `/service/school-violence-committee/` | 학폭위, 학교폭력대책심의위원회, 학폭위 대응 |
| `/service/accused/` | 학교폭력 가해자, 가해학생 지목, 학폭 신고당함 |
| `/service/victim/` | 학교폭력 피해, 학교폭력 신고, 피해학생 보호조치 |
| `/service/appeal/` | 학폭 행정심판, 학교폭력 조치 취소, 학폭 집행정지 |
| `/service/cyber/` | 사이버 학교폭력, 단톡방 따돌림, 딥페이크 학교폭력 |
| `/service/criminal/` | 촉법소년, 소년보호사건, 학교폭력 형사 |

### 칼럼으로 채워야 할 것 (롱테일)

앞으로 쓸 글의 후보입니다. **하나의 검색어 = 하나의 글** 원칙을 지키세요.
비슷한 주제로 여러 개를 쓰면 서로 순위를 갉아먹습니다(cannibalization).

**학폭위 절차**
- 학폭위 서면 의견서 작성법 / 양식
- 학폭위 출석, 실제로 어떻게 진행되나
- 학폭위 개최 통지를 받은 뒤 일정
- 학폭위에 변호사 동석이 가능한가
- 전담기구 심의는 무엇을 하는가

**가해학생 대응**
- 학교폭력 신고당했을 때 첫 3일에 할 일
- 반성문, 어떻게 써야 하나 (쓰면 불리한 경우)
- 쌍방 신고된 경우의 대응
- 학교폭력 사과문 작성 시 주의점

**피해학생**
- 학교폭력 증거 수집 방법 (카톡·녹음·진단서)
- 117 신고와 학교 신고의 차이
- 분리조치·긴급조치 요청하는 법
- 학교폭력 손해배상 청구, 얼마나 받을 수 있나
- 2차 가해가 계속될 때

**생활기록부**
- 학폭 1호 처분도 생기부에 남나요
- 학교폭력 기재 삭제 심의 준비하기
- 학폭 기록이 대입에 미치는 영향

**불복·소송**
- 학폭 행정심판 청구서 쓰는 법
- 집행정지 신청, 언제 인용되나
- 행정심판에서 진 뒤 행정소송

**상황별**
- 초등학생 학교폭력, 중고등학교와 무엇이 다른가
- 장난이었다는 주장은 통하는가
- 학교폭력과 촉법소년 연령

### 지역 키워드 (선택)

여력이 되면 `/location/` 아래에 지역 페이지를 만들 수 있습니다.

```
/location/seoul-seocho/   서초 학교폭력 변호사
/location/gyeonggi/       경기 학교폭력 변호사
```

**주의**: 지역명만 바꾼 복제 페이지를 여러 개 만들면 저품질로 평가됩니다. 해당 지역
교육지원청 정보, 관할 법원 등 실제로 다른 내용이 들어갈 때만 만드세요.

## 3. 글 쓸 때 지킬 것

### 제목

- 노리는 검색어를 **앞쪽**에 배치
- 30자 내외 (검색결과에서 잘리지 않는 길이)
- 숫자·구체성이 클릭률을 올립니다 → "학폭위 확인서 작성법 **— 제출 전 확인할 5가지**"

### 요약(description)

검색결과에서 제목 아래 보이는 문장입니다. **클릭 여부를 결정하는 문장**이므로
"~에 대해 알아보겠습니다" 같은 문장을 쓰지 마세요. 무엇을 알 수 있는지 구체적으로 씁니다.

**한글 70~90자.** (흔히 보이는 "155자" 권장은 영문 기준입니다. 한글은 글자 폭이 넓어
그대로 쓰면 검색결과에서 잘립니다.)

### 본문

- **2,000자 이상.** 짧은 글은 순위가 오르지 않습니다
- `##` 소제목을 3~6개로 나눕니다 (목차와 검색결과 이동 링크에 반영)
- 첫 문단에 검색어와 결론을 넣습니다. 사람들은 3초 안에 이탈합니다
- 표·목록을 씁니다. 스캔하기 쉬운 글이 체류시간이 깁니다
- 실제 상담에서 들은 표현을 그대로 씁니다. 사람들이 검색창에 치는 말과 같기 때문입니다

### FAQ

frontmatter의 `faq` 에 2~5개를 넣으세요. 구글이 검색결과에 접었다 펼치는 형태로 노출할 수 있고,
그러면 차지하는 면적이 두세 배가 됩니다. 이 사이트는 자동으로 `FAQPage` 구조화 데이터를 출력합니다.

### 내부 링크

칼럼 본문에서 관련 업무분야 페이지로 링크를 거세요. 이게 SEO의 기본기입니다.

```markdown
자세한 절차는 [학폭위 대응](/service/school-violence-committee/) 페이지를 참고하세요.
```

관련 칼럼 카드는 키워드가 겹치면 자동으로 연결되므로, `keywords` 를 성의 있게 채우면
내부 링크가 알아서 늘어납니다.

### 발행 주기

**주 1편**이면 충분합니다. 대신 꾸준히. 한 달에 몰아서 10편 쓰고 3개월 쉬는 것보다,
매주 1편이 훨씬 낫습니다.

## 4. 네이버 대응

### 서치어드바이저에서 할 일

- 사이트맵 제출 (한 번)
- **웹페이지 수집 요청** — 새 글을 올릴 때마다 개별 요청하면 수집이 빨라집니다
- 사이트 최적화 진단 확인

### 네이버 블로그 병행

홈페이지와 같은 글을 그대로 복사하면 안 됩니다(중복 콘텐츠). 이렇게 쓰세요.

- 블로그: 사례 중심, 대화체, 짧게. 상담 후기나 일상적인 톤
- 홈페이지: 체계적인 정리, 길게
- 블로그 글 하단에서 홈페이지의 관련 글로 링크

### 스마트플레이스

지역 검색에 잡히려면 필수입니다. 등록 후 사진과 소개를 채우고, 홈페이지 주소를 연결하세요.

## 5. 성과 확인

배포 후 3개월간은 순위 변화가 거의 없습니다. 정상입니다. 그동안은 아래만 확인하세요.

| 확인 항목 | 어디서 |
| --- | --- |
| 색인된 페이지 수 | Search Console → 페이지 |
| 어떤 검색어로 들어오는지 | Search Console → 실적 → 검색어 |
| 네이버 수집 상태 | 서치어드바이저 → 웹마스터 도구 |
| 구조화 데이터 오류 | [리치 결과 테스트](https://search.google.com/test/rich-results) |
| 속도·접근성 | [PageSpeed Insights](https://pagespeed.web.dev) |

Search Console의 **검색어 목록이 가장 중요한 자료**입니다. 예상하지 못한 검색어로 들어오는
경우가 반드시 생기는데, 그 검색어로 글을 하나 더 쓰면 바로 순위가 올라갑니다.

- **AI로 대량 생산한 글** — 구글은 걸러내고, 무엇보다 상담으로 이어지지 않습니다
- **다른 사이트 글 복붙** — 중복 콘텐츠로 평가되어 양쪽 다 손해입니다
- **백링크 구매** — 페널티 위험이 큽니다
- **비슷한 주제의 글 여러 개** — 서로 순위를 갉아먹습니다. 하나를 길게 쓰세요
